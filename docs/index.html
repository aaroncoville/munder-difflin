Hush House

A household of AI coding agents, running on your own computer.

Hush House runs command-line agents such as Claude Code, Codex, Gemini CLI, GitHub Copilot and Cursor, each as a real process in its own terminal, under the subscription or key you already have. The agents share a memory, pass each other messages through a local folder of plain files, and take work from one orchestrator, the agent you talk to. You watch them at their desks in the Study, read any terminal, and type into any session.

It is free and open source, and nothing is sold.

Run it

There are no packaged releases yet. With Node.js 18 or newer and at least one agent CLI on your PATH:

git clone https://github.com/aaroncoville/munder-difflin.git hush-house
cd hush-house
npm install
npm run dev

The README covers the prerequisites, where the app keeps its data, and how to contribute.
